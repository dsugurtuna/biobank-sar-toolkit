# Contributing to Biobank SAR Toolkit

Thank you for your interest in contributing to the Biobank SAR Toolkit! We welcome improvements, bug fixes, and new features to help the bioinformatics community handle Subject Access Requests more efficiently.

## How to Contribute

1.  **Fork the Repository**: Click the "Fork" button on the top right of the repository page.
2.  **Clone your Fork**: `git clone https://github.com/YOUR_USERNAME/biobank-sar-toolkit.git`
3.  **Create a Branch**: `git checkout -b feature/amazing-feature`
4.  **Make Changes**: Implement your feature or fix.
5.  **Commit Changes**: `git commit -m "Add amazing feature"`
6.  **Push to Branch**: `git push origin feature/amazing-feature`
7.  **Open a Pull Request**: Submit your changes for review.

## Guidelines

*   **Code Style**: Please follow the existing bash scripting style (variables in uppercase, clear comments).
*   **Documentation**: Update the README if you change how a script is used.
*   **Testing**: Ensure your changes work with standard CSV and PLINK file structures.

## Reporting Issues

If you find a bug or have a suggestion, please open an issue in the GitHub Issue Tracker.
